# Ikny Browser Extension

브라우저 주식 화면 위에 Ikny 분석 패널을 띄우는 확장 프로그램입니다.

## 설치

1. Chrome 또는 Edge에서 `chrome://extensions`를 엽니다.
2. `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 선택합니다.
4. 이 폴더를 선택합니다.

```text
/Users/song/Desktop/ikny/browser_extension
```

## 지원 페이지

```text
https://finance.naver.com/*
https://m.stock.naver.com/*
https://www.google.com/finance/*
```

## 핵심 기능

- 현재 보고 있는 종목 자동 감지
- 0~100점 매수/매도 의견
- 쉬운 용어 기반 지표 표시
- AI 일주일 전망 한 줄 요약
- 70점 이상 종목 찾기
- 드래그 이동, 최소화, 크기 조절

수정 후에는 확장 프로그램과 주식 페이지를 모두 새로고침해야 합니다.
